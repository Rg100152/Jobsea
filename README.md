## 📖 About The Project

**JobSea** is a sleek frontend simulation of a job portal interface. It features a premium dark UI with neon blue accents (`#3b82f6`), smooth interactive animations, and a seamless transition from account creation to a personalized job dashboard. 

The project demonstrates advanced CSS animations (like reactive glowing rings), vanilla JavaScript DOM manipulation, form validation, and mock backend state management all in a single file.

---

## ✨ Key Features

- **🎭 Dual Role System:** Dynamic toggle between 'Candidate' and 'Employer' which instantly updates UI elements (like testimonials) to match the selected persona.
- **✨ Interactive CSS Animations:** Features a glowing ring and floating particles that react to user input (the ring spins faster when you focus on an input field).
- **🛡️ Form Validation & Security:** Built-in validation for empty fields, password matching, and minimum password length constraints.
- **👁️ Password Visibility Toggle:** Enhanced user experience with a show/hide password feature.
- **📊 Simulated Dashboard:** Upon successful signup, seamlessly transitions to a personalized job feed displaying mock employment data (no page reload required).
- **📱 Fully Responsive:** Carefully crafted with Flexbox and CSS Grid to look perfect on desktops, tablets, and mobile devices.

---

## 🛠️ Technology Stack

- **Structure:** HTML5
- **Styling:** CSS3 (Custom Variables, Flexbox, Grid, Keyframe Animations)
- **Logic:** Vanilla JavaScript (ES6)
- **Icons:** FontAwesome 6.4
- **Typography:** Google Fonts ('Inter')
